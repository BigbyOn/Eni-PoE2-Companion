# Установка Eni-PoE2-Companion

## Требования

- Windows 10 или Windows 11, x64.
- WebView2 Runtime (Microsoft Edge WebView2). В Windows 11 он уже есть; в Windows 10 — почти всегда. Если отсутствует, установщик предложит загрузить Evergreen Runtime, либо установите его вручную: <https://developer.microsoft.com/microsoft-edge/webview2/>.
- Права обычного пользователя. Установка NSIS по умолчанию — для текущего пользователя; MSI — для всех пользователей.

## Установка

### Вариант 1 — NSIS (`Eni-PoE2-Companion-Setup.exe`)

1. Скачайте `Eni-PoE2-Companion-Setup.exe` из Releases.
2. Запустите. Выберите язык установщика (русский/английский).
3. SmartScreen: «Подробнее» → «Выполнить в любом случае» (файл не подписан сертификатом).
4. После установки приложение запускается из меню «Пуск».

### Вариант 2 — MSI (`Eni-PoE2-Companion.msi`)

1. Скачайте `Eni-PoE2-Companion.msi`.
2. Запустите, подтвердите UAC (установка для всех пользователей).
3. Завершите мастер.

### Проверка контрольной суммы

```powershell
Get-FileHash .\Eni-PoE2-Companion-Setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

Хеш должен совпасть со строкой в `SHA256SUMS.txt`.

## Первый запуск

1. Запустите **Eni-PoE2-Companion**. Откроется главное окно, в трее появится иконка.
2. Раздел **Настройки → Журнал игры**: нажмите «Найти автоматически». Если журнал не найден, укажите путь вручную (обычно `<папка игры>\logs\Client.txt`) и нажмите «Проверить».
3. Запустите Path of Exile 2 в **оконном** или **безрамочном оконном** режиме.
4. Войдите в игру — раздел **Главная** покажет локацию, уровень и текущий шаг кампании.
5. Настройте горячие клавиши при необходимости (Настройки → Горячие клавиши).

## Удаление

- Параметры Windows → Приложения → Eni-PoE2-Companion → Удалить.
- Пользовательские данные (настройки, история, скриншоты) удаляются отдельно:
  - `%APPDATA%\io.github.bigbyon.enipoe2companion`
  - `%USERPROFILE%\Pictures\Eni-PoE2-Companion`

## Частые вопросы

**Оверлей не появляется.** Проверьте, что игра не в эксклюзивном полноэкранном режиме, и что оверлей включён (Настройки → Оверлей → «Показывать оверлей»). Клавиша `Ctrl+Alt+G` скрывает и показывает оверлей.

**Локация не определяется.** Журнал может писать локации на языке клиента. Приложение предложит сопоставить неизвестное название с локацией маршрута (раздел «Кампания») и запомнит соответствие.

**Как включить ИИ.** Настройки → ИИ: выберите провайдера (DeepSeek/OpenAI), модель, при необходимости уровень рассуждения, вставьте свой API-ключ и нажмите «Сохранить настройки», затем «Проверить подключение». Без этого приложение полностью работает офлайн.

**Горячая клавиша не работает.** Сочетание занято другой программой — приложение покажет предупреждение и будет повторять попытку каждые 5 секунд. Выберите другое сочетание в настройках.

**Приложение не запускается.** Убедитесь, что установлен WebView2 Runtime. Диагностика: трей → «Открыть Eni-PoE2-Companion» → Настройки → Диагностика (кнопка «Скопировать»).
