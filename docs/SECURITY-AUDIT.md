## 3. Изменения Eni-PoE2-Companion и их обоснование

### 3.1 Сеть

Загрузка маршрута с внешнего сайта удалена: данные встроены, обновление — вместе с релизом.

С версии 0.2.0 существует ровно один сетевой сценарий — **явный запрос к ИИ** (DeepSeek/OpenAI):

- инициируется только кнопкой в окне скриншота или в настройках; фоновых вызовов нет;
- домены зафиксированы в коде: `api.deepseek.com`, `api.openai.com`; только HTTPS; редиректы запрещены (`max_redirects(0)`); таймаут 90 с;
- ключ хранится DPAPI-зашифрованным, расшифровывается непосредственно перед запросом и попадает только в заголовок `Authorization` — не в тело, не в логи, не в сообщения об ошибках;
- тело запроса: модель, сообщения, `max_tokens`, при необходимости `reasoning_effort`; изображение прикладывается только для vision-моделей OpenAI (`gpt-4o*`, `gpt-4.1*`, `gpt-5*`, `o3*`, `o4*`);
- перед отправкой рядом со снимком пишется `ai-request-*.json` (без ключа и без байтов изображения) — пользователь видит, что уходит;
- ответы в истории не сохраняются, только факт запроса;
- ошибки API показываются с кодом (401/403 — ключ, 429 — лимит), тело ошибки обрезается.

Второй сетевой сценарий — **проверка цены** через официальный trade API:

- домен один: `https://www.pathofexile.com` (`/api/trade2/...`), редиректы запрещены;
- только по кнопке «Цена», не чаще одного запроса в 3 секунды, `Retry-After` при 429 соблюдается;
- отправляется описательный `User-Agent` с названием приложения и репозиторием — этого просят GGG;
- по умолчанию проверка выключена; никаких фоновых обновлений цен и кэширования чужих данных;
- при отказе API показывается текст ошибки, ничего не повторяется автоматически.

**Импорт PoB-кода** — обработанный недоверенный ввод, без сети и без исполнения:

- принимается только код (base64 → zlib → XML), ссылки не загружаются;
- жёсткие лимиты: 2 МБ кода, 8 МБ распакованного XML, обязательный `<PathOfBuilding>` — защита от zip-бомб и мусора;
- XML разбирается потоково (`quick-xml`), из него берутся только атрибуты и текст предметов; никаких DTD/сущностей и внешних ссылок;
- результат проходит обычную валидацию схемы билдов и сохраняется в папку данных;
- ничего из кода не выполняется и не отправляется в сеть.

**Датасет статов для ценника** — ещё один запрос к тому же официальному API (`/api/trade2/data/stats`), только при включённой проверке цен:

- один запрос на 3 дня, результат — публичные игровые данные — кэшируется в `trade_stats.json` в папке данных;
- при неудаче цена считается без фильтров, ошибка показывается пользователю;
- ничего из предметов и ключей в этот запрос не попадает.

**Ссылки Wiki/PoEDB/Craft of Exile** открываются только через `link_open`; домены добавлены в белый список рядом с остальными источниками.

**Импорт гайда с Mobalytics** — единственный сценарий, где приложение запускает браузер:

- принимается только `https://mobalytics.gg/poe-2/…/builds/…`, другие хосты отклоняются;
- Edge запускается с временным профилем, без окна и без доступа к профилю пользователя, с локальным debugging-портом только на 127.0.0.1; после запроса процесс убивается вместе с дочерними, профиль удаляется;
- из страницы берутся только структурные факты (камни, снаряжение, trade-запросы), текст гайда не сохраняется и не показывается;
- результат проходит обычную валидацию схемы билдов; ничего из страницы не отправляется в сеть;
- запуск только по кнопке, один процесс на запрос.

**Курс валют** — `https://api.poe2scout.com/poe2/Leagues` (публичные 24h-цены, без ключа), фолбэк — официальные `/api/trade2/exchange/...` и `/api/trade2/search/...` + `/fetch/...`:

- запрос только при открытии «Торговли» при включённой проверке цен, кэш 5 минут, кнопка «Обновить»;
- результат — публичные агрегированные числа, ничего пользовательского не отправляется;
- ответ poe2scout кэшируется на диск на 15 минут (`scout.json`), при недоступности используется последний кэш.

**Поиск в «Торговле»** использует те же официальные endpoint'ы trade API, что и проверка цены:

- только по кнопке, не чаще одного запроса в 3 секунды, один поиск + один fetch;
- текст объявления продавца (whisper) показывается как обычный текст (экранируется) и копируется в буфер только по явному клику; ничего не отправляется автоматически;
- лига определяется тем же способом, что и для цен.

### 3.2 Внешние ссылки

`link_open(url)`:
- только `https://`;
- хост обязан входить в белый список (`mobalytics.gg`, `pathofexile.com`, `poe2speedrun.malura.de`, `github.com`, `raw.githubusercontent.com`, `maxroll.gg`);
- строка с `@` в хосте отклоняется (защита от `user@host`);
- запуск через `ShellExecuteW("open", url)`, без конкатенации командной строки;
- ошибка возвращается в UI.

### 3.3 Запуск процессов

| Место | Аргументы | Риск |
|---|---|---|
| `Store::reveal` / `reveal_data_dir` | `explorer.exe` + один путь (папка скриншотов / данных) | Путь формируется приложением из настроек; командная строка не собирается, shell не используется |
| `link_open` | `ShellExecuteW` с URL из белого списка | Только https и доверенные хосты |

Других запусков процессов нет.

### 3.4 Файловая система

- Чтение: только файл журнала (путь из настроек с проверкой), `state.json`, пользовательские билды, собственные PNG/миниатюры.
- Запись: `state.json` (атомарно), скриншоты и миниатюры (имена генерирует приложение), экспорт истории в `Документы\Eni-PoE2-Companion`, `ai-request-*.json` в папке скриншотов.
- Имена файлов скриншотов, прочитанные из `state.json`, проверяются: запрещены `/`, `\`, `..`; при несоответствии запись отбрасывается при загрузке и чтение отклоняется.
- Экспорт истории не перезаписывает чужие файлы (имя с датой и временем).

### 3.5 Буфер обмена

Только запись: горячие клавиши и кнопки «Копировать» (диагностика, путь экспорта). Чтения нет, содержимое буфера не логируется.

### 3.6 Скриншоты

- Захват — GDI `BitBlt` с экрана в области клиентского прямоугольника окна игры. Память игры не читается, в процесс игры ничего не внедряется.
- На время снимка оверлей скрывается (флаг `capturing`, поток-трекер не возвращает окно).
- Изображения остаются локально; SHA‑256 фиксируется в метаданных.
- С 0.2.0 изображение уходит в ИИ только по кнопке, только выбранной vision-модели и только вместе с локально сохранённым описанием запроса; по умолчанию ИИ выключен. Кнопка «Подготовить для ИИ» пишет только JSON-манифест и ничего не отправляет.

### 3.7 Tauri

- `capabilities/default.json`: `core:default` для окон `main` и `overlay`. Плагинов с файловыми/сетевыми/шелл-правами нет.
- Окна создаются в `setup` (`"create": false`), оверлей — `focusable: false`, `alwaysOnTop`, `skipTaskbar`.
- CSP ужесточён (см. таблицу).
- `bundle.windows.nsis.languages`: ru/en; `wix.language`: en-US.

### 3.8 Логи

- В `state.json` не попадают ключи в открытом виде (только DPAPI-блоб), нет паролей и токенов.
- Журнал игры не копируется в приложение; в историю попадают только короткие события (зона, уровень, награда).
- Скриншоты и журналы в репозиторий не попадают (`.gitignore`, отдельные папки).

## 4. Зависимости

`cargo audit` (RustSec, 1490 advisories, 464 пакета в `Cargo.lock` после возврата `ureq` для ИИ):

```
Scanning Cargo.lock for vulnerabilities (464 crate dependencies)
Crate:     proc-macro-error 1.0.4   Warning: unmaintained   RUSTSEC-2024-0370
Crate:     glib 0.18.5              Warning: unsound        RUSTSEC-2024-0429
warning: 2 allowed warnings found
```

`ureq 3.4.2` используется только модулем `ai.rs`; TLS — rustls, редиректы отключены.

- **Уязвимостей (vulnerabilities) не найдено — 0.**
- `glib` и `proc-macro-error` приходят из Linux/GTK ветки зависимостей Tauri: `cargo tree --target x86_64-pc-windows-msvc` их **не содержит**, в Windows-сборку они не попадают.
- OSV-API даёт по crates.io много ложных срабатываний (возвращает advisory без точных диапазонов версий), поэтому основным инструментом выбран `cargo audit` с базой RustSec.
- Точные версии Tauri закреплены (`=2.12.1`, `tauri-build =2.7.1`, `tauri-plugin-global-shortcut =2.3.2`), `Cargo.lock` закоммичен.

## 5. Модель угроз (кратко)

| Угроза | Митигация |
|---|---|
| Подмена маршрута/билда по сети | сетевых загрузок нет; данные встроены и проверяются схемой при старте |
| Вредоносный `state.json` (ручная правка) | санитизация значений, проверка имён файлов, повреждённый файл не перезаписывается |
| Prompt-injection через содержимое журнала | ИИ не подключён; журнал парсится как данные, не исполняется |

| Перехват фокуса/ввода | оверлей `WS_EX_NOACTIVATE`, никакой эмуляции ввода |
| Произвольный запуск команд | нет shell-команд; `explorer.exe` с фиксированным путём; ссылки через белый список |
| Зависание из-за блокировок | фиксированный порядок захвата, тесты, блокирующие оконные вызовы вне мьютексов |

## 6. Остаточные риски

1. **Неподписанные установщики.** SmartScreen предупреждает; SHA‑256 приложены к релизу. Для продакшена нужен сертификат подписи кода.
2. **Чтение журнала** — путь берётся из настроек; приложение читает только текстовый файл и не исполняет его содержимое.
3. **Сторонние ссылки** открываются в браузере пользователя — ответственность за содержимое сайтов лежит на них.
4. **Захват экрана** в области окна игры: если поверх игры открыто другое приложение, оно попадёт в снимок; снимки остаются локально.
5. **ИИ передаёт данные третьей стороне** (DeepSeek/OpenAI) по явной команде пользователя: контекст персонажа и, для vision-моделей, выбранный скриншот. Это осознанный выбор пользователя; по умолчанию ИИ выключен, ключ нужен свой. Состав запроса фиксируется локальным `ai-request-*.json`.
