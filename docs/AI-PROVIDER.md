# ИИ-провайдер

С версии **0.2.0** ИИ подключён по-настоящему: DeepSeek и OpenAI (оба — OpenAI-совместимый `/chat/completions`). Вызов выполняется **только по кнопке** в окне скриншота и только когда ИИ включён, провайдер выбран и ключ сохранён.

## Что настраивается

| Параметр | Где | Примечание |
|---|---|---|
| Провайдер | Настройки → ИИ | DeepSeek или OpenAI |
| Модель | Настройки → ИИ | список подсказок + любое своё значение (например, flash-версия провайдера) |
| Уровень рассуждения | Настройки → ИИ | `auto` / `low` / `medium` / `high`; при выборе не-`auto` уходит полем `reasoning_effort` |
| API-ключ | Настройки → ИИ | шифруется Windows DPAPI, в JSON только base64-блоб |
| Проверка | кнопка «Проверить подключение» | короткий запрос без изображений |

## Что происходит при запросе

1. Собирается **локальное описание** запроса: задача, провайдер, модель, уровень рассуждения, ссылки на снимки (имя, тип, размер, SHA‑256, заметка), контекст (имя, класс, восхождение, уровень, акт, зона, билд, этап, патч, текущая цель, следующие шаги), вопрос игрока.
2. Описание записывается в `ai-request-<время>.json` рядом со скриншотами — это то, что уйдёт (без ключа и без байтов изображения).
3. Ключ расшифровывается DPAPI и попадает **только** в заголовок `Authorization`.
4. Если выбранная модель умеет изображения (OpenAI `gpt-4o*`, `gpt-4.1*`, `gpt-5*`, `o3*`, `o4*`), PNG прикрепляется как `image_url` с data-URL. Для текстовых моделей (DeepSeek) изображение не отправляется: в запрос идут описание, заметка и контекст, а в ответе видно пометку «Скриншот не отправлялся».
5. Ответ показывается в модальном окне: текст, при наличии — блок «Рассуждения», модель, расход токенов и путь к сохранённому описанию запроса.

## Границы безопасности

- Домены фиксированы в коде: `api.deepseek.com`, `api.openai.com`. Только HTTPS, редиректы запрещены (`max_redirects(0)`), таймаут 90 с.
- Никаких фоновых запросов: нет вызовов при старте, обновлении данных, смене зоны или скриншоте.
- Ключ не пишется в логи, не попадает в сообщения об ошибках, не уходит никуда, кроме заголовка.
- Ошибки API показываются пользователю (401/403 — «ключ отклонён», 429 — лимит и т.д.), тело ошибки обрезается.
- В `state.json` нет ни ключа в открытом виде, ни истории ответов (она не сохраняется).

## Почему DeepSeek не видит скриншот

Публичный API DeepSeek — текстовый, без vision. Поэтому для DeepSeek анализ строится на контексте и заметке. Если нужен разбор именно картинки, выберите OpenAI-модель с изображениями (например `gpt-4o-mini`).

## Ошибки и что делать

| Сообщение | Причина | Решение |
|---|---|---|
| «ИИ выключен…» | не включён провайдер или чекбокс | Настройки → ИИ: включить, выбрать провайдера, сохранить |
| «Не задан API-ключ» | ключ не сохранён | вставить ключ и нажать «Сохранить настройки» |
| «Ключ отклонён (401/403)» | неверный/отозванный ключ, нет доступа к модели | проверить ключ и доступ к модели в кабинете провайдера |
| «Модель или адрес не найдены (404)» | опечатка в id модели | выбрать модель из списка или проверить id |
| «HTTP 400 … reasoning_effort» | модель не принимает этот параметр | поставить уровень рассуждения «Авто» |
