# Известные ограничения Eni-PoE2-Companion 0.1.0

Ниже — честный список того, что в первой версии **не** работает или работает частично. Ничего из этого не маскируется заглушками: если источник данных не даёт сведений, приложение показывает это в интерфейсе и предлагает ручной ввод.

## Данные игры

1. **Русские названия зон есть в данных (90 зон), но не все проверены на живом клиенте.** Четыре (`Берег реки`, `Лагерь Клирфелл`, `Клирфелл`, `Красная Долина`) сверены с реальным журналом; остальные — собственный перевод. Если клиент пишет иначе, работает сопоставление по внутреннему id области (`G1_1`, `G1_town`) или ручная привязка: приложение предлагает её при первом появлении неизвестной зоны и запоминает выбор.
2. **Класс и имя — только из строки повышения уровня.** Если клиент их не пишет (другой язык, другая версия), поля заполняются вручную; имя свежего профиля подставляется из журнала автоматически при первом повышении уровня.
3. **Уровень персонажа.** Определяется по строке вида `… (Класс) достигает N уровня`. Повышения уровня других игроков в группе не учитываются (нет имени/класса — событие отбрасывается).
4. **Постоянные награды.** Распознаются только те, что клиент пишет в журнал: сопротивления, дух, очки пассивных умений, максимум жизни/маны, слот амулета. Награды, которые в журнал не попадают (например, выбор предмета у торговца), отмечаются вручную.
5. **Кампания.** Маршрут (115 шагов, 6 актов, патч 0.5.5) встроен в приложение. Обновление — только с новой версией приложения; сетевой загрузки намеренно нет. Пропущенные шаги вручную отмечаются кнопкой.
6. **Акт определяется по шагу маршрута.** Если локация неизвестна, акт не меняется до сопоставления или ручного выбора.

## Скриншоты

7. **Захват — только клиентской области окна игры** (GDI `BitBlt`). Если поверх игры висит другое приложение, оно попадёт в снимок.
8. **Оверлей скрывается на время снимка** (~120 мс). В этот момент он исчезает с экрана — это ожидаемое поведение, а не сбой.
9. **ИИ требует ключа и работает только по кнопке.** DeepSeek — текстовая модель: скриншот ей не отправляется, анализ строится на контексте и заметке. Разбор изображения возможен только vision-моделью OpenAI. Ответы ИИ не сохраняются в истории (только факт запроса).

## Оверлей

10. **Эксклюзивный полноэкранный режим игры не поддерживается** — как и у любого оверлея. Нужен оконный или безрамочный оконный режим.
11. **Оверлей показывается только при активном окне игры** (или окна помощника). Это настройка по умолчанию; её можно отключить.
12. **Размер окна оверлея равен панели.** Клик мимо панели попадает в игру; перетаскивание — за заголовок (в компактном режиме — за всю строку).

## Интерфейс и данные

13. **Нет нативной установки темы/шрифтов** — используется системный WebView2 и шрифты Windows (Segoe UI, Palatino/Book Antiqua). На системах без этих шрифтов вид может отличаться.
14. **История ограничена 5000 записями** (старые вытесняются), награды профиля — 200, уровни — 200.
15. **Экспорт истории** пишется в `Документы\Eni-PoE2-Companion` с автоматическим именем; выбор места через диалог не реализован.
16. **Путь к журналу и папка скриншотов** выбираются системным диалогом («Обзор…») или вводятся текстом с кнопкой проверки.
17. **ИИ зависит от внешнего сервиса.** Нужен интернет, свой API-ключ и оплаченный доступ у провайдера. При ошибке сети/ключа показывается сообщение; офлайн-функции при этом не страдают.
18. **Нет автообновления приложения.** Новая версия — новый установщик с GitHub Releases.

## Сборка и распространение

19. **Установщики не подписаны сертификатом** — SmartScreen может предупредить. SHA‑256 приложены к релизу; как подключить подпись — в [CODE-SIGNING.md](CODE-SIGNING.md).
20. **Проверено на Windows 11 x64** (сборка, установка, запуск, удаление). Windows 10 x64 использует тот же WebView2/MSVC‑рантайм, но отдельный прогон на Windows 10 не выполнялся.
21. **MSI собран, но не устанавливался на этой машине** (для установки MSI нужны права администратора). Проверены сборка, состав и корректность базы MSI; NSIS-установщик проверен полным циклом: тихая установка → запуск → удаление.
22. **Скриншоты и журналы пользователя не входят в репозиторий** и не отправляются разработчику.
23. **Оценка предмета — эвристика по ключевым словам**, а не калькулятор урона: она подсказывает, какие приоритеты билда предмет покрывает, но не считает DPS и не сравнивает с надетым предметом автоматически (сравнить можно глазами или спросить ИИ).
24. **Импорт предмета требует буфера обмена**: предмет копируется в игре (`Ctrl+C`), приложение читает текст. Свои таблицы предметов и базу модов оно не содержит.
25. **Цены и трейд не проверяются** — намеренно: это сетевые запросы к торговой площадке с лимитами и требованиями к частоте, вне локальной модели приложения.
26. **Статистика сессии сбрасывается при перезапуске** (сессия = запуск приложения); история при этом сохраняется.
27. **Проверка цены — ориентир, а не оценка редкости**: для уникальных предметов поиск идёт по имени и базе, для редких — только по базе и редкости, без фильтров по модификаторам (карта статов trade API пока не подключена). Точную цену смотрите по ссылке «Открыть на trade».
28. **Цены зависят от лиги и времени**: лига определяется автоматически, при необходимости задаётся вручную; значения — снимок на момент запроса, не история.
29. **Trade API ограничивает частоту**: не чаще одного запроса в 3 секунды, при 429 приложение просит подождать; массовой проверки цен нет.
30. **Импорт PoB — структурный снимок.** Класс, восхождение, камни, предметы и число узлов дерева читаются; идентификаторы узлов PoB не сопоставлены с названиями (нет базы дерева PoE2), поэтому дерево показывается числом узлов. Этапы прокачки по уровням импорт не создаёт.
31. **PoB-код принимается только в виде кода**, не ссылкой `pobb.in`: сетевой загрузки чужих страниц нет. Ссылку нужно открыть в браузере и скопировать сам код.
32. **Фильтры ценника — эвристика**: сопоставление идёт по форме текста мода (`#` вместо чисел), поэтому нестандартные/составные моды могут не найтись; отрицательные моды не фильтруются, а точные минимальные значения сужают выдачу (по умолчанию 2 мода). Датасет статов обновляется раз в 3 дня.
33. **Опасные моды карт** определяются по ключевым словам EN/RU; список покрывает частые угрозы, но не претендует на полноту игровых аффиксов.
34. **Формат PoB может отличаться между версиями/форками.** Разбор устойчив к отсутствующим секциям, но экзотические варианты могут дать частичный результат — приложение сообщает об ошибке, а не создаёт пустой билд.
