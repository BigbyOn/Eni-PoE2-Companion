# Известные ограничения Eni-PoE2-Companion 0.1.0

Ниже — честный список того, что в первой версии **не** работает или работает частично. Ничего из этого не маскируется заглушками: если источник данных не даёт сведений, приложение показывает это в интерфейсе и предлагает ручной ввод.

## Данные игры

1. **Русские названия зон покрыты частично.** Клиент пишет в журнал локализованные названия (`Берег реки`, `Лагерь Клирфелл`, `Клирфелл`, `Красная Долина` — проверены на реальном журнале). Остальные сопоставляются по внутреннему id области, если он известен (`G1_1`, `G1_town`), либо вручную: приложение предлагает сопоставить неизвестное название при первом появлении и запоминает выбор. Пока соответствие не задано, оверлей показывает локацию как есть, а шаг кампании не двигается.
2. **Класс и имя — только из строки повышения уровня.** Если клиент их не пишет (другой язык, другая версия), поля заполняются вручную; имя свежего профиля подставляется из журнала автоматически при первом повышении уровня.
3. **Уровень персонажа.** Определяется по строке вида `… (Класс) достигает N уровня`. Повышения уровня других игроков в группе не учитываются (нет имени/класса — событие отбрасывается).
4. **Постоянные награды.** Распознаются только те, что клиент пишет в журнал: сопротивления, дух, очки пассивных умений, максимум жизни/маны, слот амулета. Награды, которые в журнал не попадают (например, выбор предмета у торговца), отмечаются вручную.
5. **Кампания.** Маршрут (115 шагов, 6 актов, патч 0.5.5) встроен в приложение. Обновление — только с новой версией приложения; сетевой загрузки намеренно нет. Пропущенные шаги вручную отмечаются кнопкой.
6. **Акт определяется по шагу маршрута.** Если локация неизвестна, акт не меняется до сопоставления или ручного выбора.

## Скриншоты

7. **Захват — только клиентской области окна игры** (GDI `BitBlt`). Если поверх игры висит другое приложение, оно попадёт в снимок.
8. **Оверлей скрывается на время снимка** (~120 мс). В этот момент он исчезает с экрана — это ожидаемое поведение, а не сбой.
9. **Нет анализа изображений в 0.1.0.** Снимок, миниатюра, метаданные, SHA‑256 и JSON‑описание запроса создаются локально; отправка в ИИ появится позже.

## Оверлей

10. **Эксклюзивный полноэкранный режим игры не поддерживается** — как и у любого оверлея. Нужен оконный или безрамочный оконный режим.
11. **Оверлей показывается только при активном окне игры** (или окна помощника). Это настройка по умолчанию; её можно отключить.
12. **Размер окна оверлея равен панели.** Клик мимо панели попадает в игру; перетаскивание — за заголовок (в компактном режиме — за всю строку).

## Интерфейс и данные

13. **Нет нативной установки темы/шрифтов** — используется системный WebView2 и шрифты Windows (Segoe UI, Palatino/Book Antiqua). На системах без этих шрифтов вид может отличаться.
14. **История ограничена 5000 записями** (старые вытесняются), награды профиля — 200, уровни — 200.
15. **Экспорт истории** пишется в `Документы\Eni-PoE2-Companion` с автоматическим именем; выбор места через диалог не реализован.
16. **Путь к журналу и папка скриншотов** вводятся текстом с кнопкой проверки; системного диалога выбора файла нет.
17. **ИИ не подключён.** Ключ можно сохранить (Windows DPAPI), но сетевых вызовов нет, поле провайдера только готовит будущую интеграцию.
18. **Нет автообновления приложения.** Новая версия — новый установщик с GitHub Releases.

## Сборка и распространение

19. **Установщики не подписаны сертификатом** — SmartScreen может предупредить. SHA‑256 приложены к релизу.
20. **Проверено на Windows 11 x64** (сборка, установка, запуск, удаление). Windows 10 x64 использует тот же WebView2/MSVC‑рантайм, но отдельный прогон на Windows 10 не выполнялся.
21. **MSI собран, но не устанавливался на этой машине** (для установки MSI нужны права администратора). Проверены сборка, состав и корректность базы MSI; NSIS-установщик проверен полным циклом: тихая установка → запуск → удаление.
22. **Скриншоты и журналы пользователя не входят в репозиторий** и не отправляются разработчику.
