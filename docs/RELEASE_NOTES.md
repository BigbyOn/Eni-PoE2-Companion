# Eni-PoE2-Companion v0.2.0

Помощник для **Path of Exile 2** на Windows 10/11 x64: отслеживание прогресса по журналу игры, профили персонажей, локальные билды, история, скриншоты, оверлей и — новое — **ИИ-анализ по кнопке**.

Основано на [poe2overlay](https://github.com/maluramichael/poe2overlay) © 2026 Michael Malura (MIT). Лицензия и уведомления сохранены.

## В релизе

| Файл | Что это |
|---|---|
| `Eni-PoE2-Companion-Setup.exe` | установщик NSIS (русский/английский интерфейс установки, рекомендуется) |
| `Eni-PoE2-Companion.msi` | установщик MSI (для всех пользователей) |
| `SHA256SUMS.txt` | контрольные суммы SHA‑256 обоих установщиков |

Установщики не подписаны — SmartScreen может предупредить (**Подробнее → Выполнить в любом случае**). Как подключить подпись: [docs/CODE-SIGNING.md](https://github.com/BigbyOn/Eni-PoE2-Companion/blob/main/docs/CODE-SIGNING.md).

## Новое в 0.2.0

### ИИ-анализ (по желанию, по кнопке)

- Провайдеры: **DeepSeek** и **OpenAI**.
- Выбор модели: список подсказок + любое своё значение (например, flash-версия провайдера).
- **Уровень рассуждения**: авто / низкий / средний / высокий (уходит как `reasoning_effort`, если выбран не «авто»).
- Кнопка «Проверить подключение» в настройках.
- Действия в окне скриншота: «Разобрать предмет», «Что улучшить», «Сравнить с билдом», плюс свободный вопрос.
- В ответе: текст, при наличии — блок рассуждений модели, модель, расход токенов и пометка, был ли отправлен снимок.
- Перед отправкой рядом со снимком сохраняется `ai-request-*.json` — видно, какие данные уходят.
- Ключ хранится только зашифрованным (Windows DPAPI) и используется лишь в заголовке `Authorization`.
- Изображения отправляются только vision-моделям OpenAI (`gpt-4o*`, `gpt-4.1*`, `gpt-5*`, `o3*`, `o4*`). Текстовым моделям (DeepSeek) уходят описание, заметка и контекст персонажа и билда.

### Русские названия всех локаций

- 90 зон кампании получили русские подписи; составные показываются как «Нгакану → Сердце племени».
- Русские названия из журнала сопоставляются напрямую; ручная таблица соответствий осталась для нестандартных случаев.
- Проверенные на реальном клиенте: `Берег реки`, `Лагерь Клирфелл`, `Клирфелл`, `Красная Долина`.

## Установка

1. Скачайте `Eni-PoE2-Companion-Setup.exe` (или `.msi`).
2. Запустите, подтвердите SmartScreen при необходимости.
3. Запустите приложение: оно живёт в трее, окно открывается по иконке или `Shift+Space`.
4. Запустите игру в **оконном** или **безрамочном оконном** режиме.
5. Если журнал не нашёлся — Настройки → «Журнал игры» → путь к `Client.txt` → «Проверить».
6. Для ИИ: Настройки → ИИ → провайдер, модель, ключ, «Проверить подключение». Без этого всё работает офлайн.

Windows 10/11 содержат WebView2; если его нет — Evergreen Runtime: <https://developer.microsoft.com/microsoft-edge/webview2/>.

## Известные ограничения

- ИИ требует своего API-ключа и интернета; DeepSeek не читает изображения (для разбора снимка нужна vision-модель OpenAI).
- Ответы ИИ не сохраняются в истории — только факт запроса.
- Не все русские названия зон сверены с живым клиентом (4 проверены, остальные — перевод; при расхождении помогает id области или ручная привязка).
- Эксклюзивный полноэкранный режим игры не поддерживается.
- Установщики не подписаны сертификатом.

Полный список: [docs/KNOWN-LIMITATIONS.md](https://github.com/BigbyOn/Eni-PoE2-Companion/blob/main/docs/KNOWN-LIMITATIONS.md).
