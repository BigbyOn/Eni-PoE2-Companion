# Eni-PoE2-Companion v0.1.0

Первый релиз персонального помощника для **Path of Exile 2** на Windows 10/11 x64: отслеживание прогресса по журналу игры, профили персонажей, локальные билды, история, скриншоты и оверлей поверх игры.

Основано на [poe2overlay](https://github.com/maluramichael/poe2overlay) © 2026 Michael Malura (MIT). Лицензия и уведомления сохранены.

## В релизе

| Файл | Что это |
|---|---|
| `Eni-PoE2-Companion-Setup.exe` | установщик NSIS (русский/английский интерфейс установки, рекомендуется) |
| `Eni-PoE2-Companion.msi` | установщик MSI (для всех пользователей) |
| `SHA256SUMS.txt` | контрольные суммы SHA‑256 обоих установщиков |

Проверка после скачивания:

```powershell
Get-FileHash .\Eni-PoE2-Companion-Setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

## Установка

1. Скачайте `Eni-PoE2-Companion-Setup.exe` (или `.msi`).
2. Запустите. Установщик не подписан — SmartScreen: **Подробнее → Выполнить в любом случае**.
3. Запустите приложение: оно живёт в трее, окно открывается по иконке или `Shift+Space`.
4. Запустите игру в **оконном** или **безрамочном оконном** режиме.
5. Если журнал не нашёлся автоматически — Настройки → «Журнал игры» → укажите путь к `Client.txt` и нажмите «Проверить».

Windows 10/11 содержат WebView2; если его нет, установите Evergreen Runtime: <https://developer.microsoft.com/microsoft-edge/webview2/>.

## Что умеет 0.1.0

- **Отслеживание игры**: автопоиск журнала (Steam/standalone), `Client.txt` и `LatestClient.txt`, UTF‑8/UTF‑16LE, восстановление состояния после перезапуска, усечение и замена файла, история событий.
- **Русский клиент**: `[SCENE] Set Source [Берег реки]`, `достигает N уровня`, `Игрок … получил …`; проверенные соответствия локаций, сопоставление по id области, ручное сопоставление неизвестных зон с запоминанием.
- **Персонаж**: несколько профилей, имя/класс из журнала или вручную, уровень, акт, зона, награды, история уровней, задачи.
- **Билд**: локальный JSON-формат, встроенный **Lightning Arrow — Deadeye** (5 этапов, 15 пунктов чек-листа), приоритеты экипировки, ссылки на первоисточники.
- **Кампания**: 115 шагов / 6 актов (0.5.5), режимы «все» и «только обязательные», ручной выбор и отметка шагов.
- **История**: фильтры, экспорт JSON.
- **Скриншоты**: снимок окна игры по `Ctrl+Alt+S`, миниатюры, тип снимка, заметка, SHA‑256, подготовка JSON-описания для будущего ИИ (без сети).
- **Оверлей**: компактный/стандартный/расширенный, прозрачность, масштаб, положение, скрытие, без перехвата фокуса.
- **Настройки**: RU/EN, путь к журналу, горячие клавиши, папка скриншотов, таблица локаций, провайдер ИИ (ключ через DPAPI), диагностика.

## Безопасность

- Нет сетевых запросов: обновления данных выходят вместе с новой версией.
- Нет чтения памяти игры, внедрения и автоматизации ввода.
- Нет телеметрии и аналитики.
- Внешние ссылки — только https и только доверенные хосты.
- Подробный аудит: [docs/SECURITY-AUDIT.md](https://github.com/BigbyOn/Eni-PoE2-Companion/blob/main/docs/SECURITY-AUDIT.md) (в репозитории).

## Известные ограничения

- ИИ-анализ не подключён: интерфейс и локальная подготовка запроса есть, отправки нет.
- Русские названия зон покрыты частично; неизвестные сопоставляются вручную (приложение запоминает).
- Имя/класс определяются только по строке повышения уровня.
- Эксклюзивный полноэкранный режим игры не поддерживается.
- Установщики не подписаны сертификатом.
- История ограничена 5000 записями.

Полный список: [docs/KNOWN-LIMITATIONS.md](https://github.com/BigbyOn/Eni-PoE2-Companion/blob/main/docs/KNOWN-LIMITATIONS.md).
