# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.11.0] — 2026-11-13

### Добавлено

- **Выбор варианта билда Mobalytics.** «Импорт по ссылке» → «Проверить варианты»: страница разбирается один раз, в списке появляются все варианты (сколько камней и предметов в каждом). Импортируется выбранный; его метка («Вариант 2») сохраняется в гайде и в названии билда. Сейчас страница Lightning Arrow Deadeye даёт 4 варианта.
- **Список апгрейдов по гайду.** В карточке гайда кнопка «Список апгрейдов»: для пяти главных слотов (оружие, нагрудник, шлем, перчатки, ботинки; если чего-то нет — амулет/пояс) выполняются trade-запросы из гайда, показываются минимум, медиана, число лотов и ссылка на поиск. Запросы идут с паузами ~1.6 с, всего до ~10 секунд.
- **Пустые whisper больше не показываются**: у лотов со статусом `securable` кнопка копирования скрыта.

### Изменено

- **Импорт Mobalytics переведён с `--dump-dom` на DevTools-протокол**: Edge 157 перестал отдавать DOM через dump-dom (пустой вывод). Теперь приложение поднимает Edge с локальным debugging-портом, ждёт появления `__PRELOADED_STATE__` и читает `outerHTML` через CDP; всё ограничено 120 секундами, процесс Edge убивается вместе с дочерними, временный профиль удаляется.
- Версия 0.11.0.

## [0.10.0] — 2026-11-13

### Добавлено

- **Курс валют из poe2scout** (24-часовое среднее, без ключа): `GET https://api.poe2scout.com/poe2/Leagues` отдаёт текущую лигу (`IsCurrent`) и `DivinePrice` в exalted. Это надёжнее обмена, где по лиге было 0–1 предложение:
  - приоритет: poe2scout → официальный обмен → ценники Divine Orb;
  - лига берётся из `IsCurrent` (сейчас Forbidden Rites, 655 exalted за divine), кэш 15 минут на диск;
  - активная лига poe2scout используется и для цен, если в настройках лига не задана.
- **Ссылка на поиск по id**: после проверки цены и поиска открывается `…/trade2/search/poe2/{лига}/{search.id}` — тот же поиск, а не только текстовый запрос.

### Изменено

- **Фильтры ценника с допуском 10%**: минимальные значения модов уменьшаются на 10% (жизнь 100 → минимум 90) — находятся похожие лоты, а не только «не хуже».
- Если с полным набором модов ничего не найдено, поиск повторяется по двум главным модам, и только затем — по базе и редкости.
- Версия 0.10.0.

## [0.9.0] — 2026-11-13

### Добавлено

- **Курс валют в разделе «Торговля»**: «1 Divine ≈ N Exalted» с указанием лиги, числа предложений и источника.
  - данные берутся из **официального bulk-exchange** (`/api/trade2/exchange/poe2/{лига}`): у предложения `exchange` — сколько продавец хочет (exalted), `item` — сколько отдаёт (divine), курс = отношение;
  - если обмен по лиге пуст, используется **фолбэк по ценникам Divine Orb**: поиск `Divine Orb` с фильтром цены в exalted, курс = медиана цен;
  - перебираются лиги: выбранная/авто, остальные PoE2-лиги, Standard — пока не найдётся предложение (в челлендж-лигах обмен сейчас пуст, поэтому курс показывается по Standard с явной подписью);
  - кэш на 5 минут, обновление кнопкой; запрос только при открытии раздела «Торговля» (если цены включены).

### Изменено

- Версия 0.9.0.

### Исправлено

- Курсы больше не «выдумываются»: если официальный API не дал ни одного предложения, показывается «Курс недоступен», а не приблизительное число.

## [0.8.0] — 2026-11-13

### Добавлено

- **Импорт билда с Mobalytics по ссылке.** Приложение открывает страницу билда в установленном Microsoft Edge без окна (Cloudflare пропускает только настоящий браузер, обычный HTTP-запрос получает челлендж), забирает из `__PRELOADED_STATE__` только структурные факты: название, класс, восхождение, группы камней с поддержками, снаряжение по слотам с модификаторами и **готовые trade-запросы**. Текст гайда не копируется, источник — ссылка на страницу.
  - В карточке гайда у каждого предмета кнопка «Найти»: запускает запрос из гайда (с его фильтрами по модам) и показывает 3 лота с ценой, продавцом и whisper.
  - Импорт ограничен страницами `mobalytics.gg/poe-2/**/builds/**`, один запрос по кнопке, временный профиль Edge удаляется.
- **Быстрая цена по горячей клавише** (`Ctrl+Alt+KeyP`): читает предмет из буфера (наведи курсор и нажми `Ctrl+C`), считает цену с теми же фильтрами по модам и показывает баннер в оверлее: имя, диапазон, число лотов.
- **Статус продавца** в результатах торговли и в поиске по гайду: зелёная точка — онлайн, серая — нет данных/офлайн.

### Изменено

- Горячих клавиш стало десять (добавлена «Быстрая цена»); раздел «Мой билд» получил кнопку «Импорт по ссылке» и карточку гайда.
- Версия 0.8.0.

### Ограничения

- Курсы валют (Divine/Exalted) в этот релиз не вошли: официальный bulk-exchange отдаёт по этой лиге 0–1 предложение с неоднозначными суммами, а сторонние API (poe2scout) не отвечают по известным путям. Нужен отдельный проверенный источник — следующий шаг.

## [0.7.0] — 2026-11-13

### Добавлено

- **Чек-лист локации.** Отдельная панель в оверлее (`Ctrl+Alt+J`) помогает понять, всё ли сделано в текущей локации:
  - счётчик редких (`+`/`−`), отметка мини-босса, список механик с галочками (Breach, Ritual, Expedition, Delirium, Tower — редактируется в настройках);
  - таймер локации и подсказка «Всё отмечено — можно идти дальше», когда мини-босс и все механики отмечены;
  - панель сбрасывается при входе в новую локацию; при выходе в историю пишется строка «Локация: N редких, босс: да/нет, механик X/Y»;
  - опция «открывать чек-лист при входе в новую локацию».
- **Раздел «Торговля».** Поиск по названию или базе через официальный trade API: первые 10 самых дешёвых онлайн-лотов с ценой, продавцом и кнопкой «Копировать whisper» (вставить в игру) и «Открыть на trade».
- **«Найти» у предметов билда.** В списке снаряжения билда у каждой строки появилась кнопка, которая открывает «Торговлю» с уже подставленной базой.
- Конфликт горячих клавиш больше не мешает сохранять настройки: занятая комбинация показывается предупреждением, остальные настройки сохраняются.

### Изменено

- Разделов в боковом меню стало восемь (добавлена «Торговля»); горячих клавиш — девять.
- Версия 0.7.0.

## [0.6.0] — 2026-11-13

### Добавлено

- **Ценник с учётом модификаторов.** При проверке цены приложение загружает официальный датасет статов (`/api/trade2/data/stats`), сопоставляет строки модов предмета с `explicit.stat_*` и добавляет до трёх фильтров в запрос к trade API:
  - количество модов настраивается (0–3, по умолчанию 2) — компромисс между точностью и числом лотов;
  - защитные моды (жизнь/сопротивления) идут первыми, отрицательные моды не фильтруются;
  - если с фильтрами ничего не найдено, поиск автоматически повторяется по базе и редкости, а в подписи сказано, что показаны базовые цены;
  - датасет кэшируется на диск (`trade_stats.json`, 3 дня) — один запрос вместо каждого клика.
- **Предупреждения об опасных модах карт/вайстоунов.** Для импортированного предмета показываются красные метки: рефлект, нет регенерации, дополнительный урон монстров, иммунитет, крит/скорость монстров, проклятия, снижение максимума сопротивлений, заряды флаконов (EN/RU).
- **Ссылки Wiki / PoEDB / Craft of Exile** на импортированный предмет (по базе/имени); домены добавлены в белый список `link_open`.
- Исправлено распознавание свойств предмета: строки-моды, содержащие «Physical Damage», «Energy Shield» и т.п., больше не считаются свойствами — это чинило разбор карт и вайстоунов.
- Список предметов на странице «Мой билд» теперь загружается при открытии раздела (раньше — только после импорта).

### Изменено

- Версия 0.6.0.

## [0.5.0] — 2026-11-13

### Добавлено

- **Импорт билда из Path of Building (PoB2).** Кнопка «Импорт PoB-кода» на странице «Мой билд»:
  - принимает код `base64(zlib(xml))`, который PoB отдаёт через «Import/Export Build» → «Copy code»;
  - разбирает только структурные факты: класс, восхождение, уровень, группы камней (основной навык + поддержки), тексты предметов, число узлов дерева;
  - создаёт обычный локальный билд (валидируется той же схемой), сохраняет его в папку билдов и делает активным;
  - источники и дисклеймер указывают на Path of Building; тексты гайдов не копируются.
  - Декодирование защищено лимитами: не более 2 МБ кода и 8 МБ распакованного XML, обязательное наличие `<PathOfBuilding>`; ничего не исполняется.

### Изменено

- Список билдов в интерфейсе обновляется автоматически, если билд импортирован или появился извне.
- Версия 0.5.0.

### Исправлено

- Импортированный билд сразу отображается в списке и выбирается активным (раньше список обновлялся только при перезапуске).

## [0.4.0] — 2026-11-13

### Добавлено

- **Проверка цен через официальный trade API PoE2.** У импортированного предмета появилась кнопка «Цена»:
  - используется официальный API (`/api/trade2/data/leagues`, `/api/trade2/search/poe2/{лига}`, `/api/trade2/fetch/…`), а не сторонние сайты;
  - лига определяется автоматически (сейчас — актуальная «Forbidden Rites»), можно задать вручную в настройках;
  - считается минимум, медиана и число лотов, показываются примеры цен и кнопка «Открыть на trade» с уже собранным запросом;
  - проверка выключена по умолчанию, выполняется только по нажатию, не чаще одного запроса в 3 секунды, `Retry-After` при 429 соблюдается, отправляется описательный `User-Agent`.
  - Для редких предметов это ориентир по базе и редкости (без фильтров по модификаторам) — в интерфейсе есть пометка и ссылка на trade для точного поиска.

### Изменено

- В настройках появился раздел «Цены предметов» (включение и лига).
- Версия 0.4.0.

## [0.3.0] — 2026-11-13

### Добавлено

- **Импорт предмета из буфера обмена.** В игре наведи курсор на предмет и нажми `Ctrl+C`, затем в приложении — «Импорт из буфера» (или горячая клавиша `Ctrl+Alt+I`). Приложение читает текст, разбирает его и сохраняет локально: класс, редкость, имя, база, уровень предмета, качество, требования, модификаторы, флаги (осквернён/неопознан/…).
- **Локальная оценка под билд.** Эвристика по ключевым словам (английский и русский клиент): находит жизнь, сопротивления, урон, характеристики, дух, ману, скорость передвижения; предупреждает, если у брони нет жизни/сопротивлений, предмет неопознан, уровень предмета низкий для персонажа или в тексте нет модификаторов. Оценка и список «подходит/замечания» видны в разделе «Мой билд».
- **ИИ по тексту предмета.** Кнопка «Спросить ИИ» у импортированного предмета отправляет текст предмета и контекст персонажа/билда. Это работает и с текстовыми моделями (DeepSeek), которым недоступны скриншоты.
- **Regex-лист для вендора и сундука.** Настраиваемый список (название + regex) в настройках; горячая клавиша `Ctrl+Alt+R` открывает его прямо в оверлее поверх игры; клик копирует regex в буфер и закрывает список. Список показывается даже если оверлей скрыт.
- **Статистика сессии.** Длительность сессии, время в текущей зоне, смерти, полученные уровни и число посещённых зон — на «Главной». Смерти распознаются из журнала (`has been slain`, `был повержен` и др.).
- История пополнилась событиями «Предмет» и «Смерть».

### Изменено

- Горячих клавиш стало восемь: добавлены «Импорт предмета» и «Regex-список».
- `state.json`: новые поля `items` и `regexes`; для частично заполненного файла подставляются значения по умолчанию (исправлено: раньше отсутствующие `regexes`/`zone_aliases` превращались в пустые списки).
- Версия 0.3.0.

### Исправлено

- Частично заполненный `state.json` больше не теряет стартовые regex-ы и таблицу соответствий локаций.

## [0.2.0] — 2026-11-12

### Добавлено

- **ИИ-анализ (по желанию, по кнопке).** Подключены DeepSeek и OpenAI через OpenAI-совместимый API:
  - выбор провайдера, модели (список + любой свой id, например flash-версия) и **уровня рассуждения** (`auto`/`low`/`medium`/`high` → `reasoning_effort`);
  - кнопка «Проверить подключение» в настройках;
  - разбор предмета, «что улучшить», сравнение с билдом и свободный вопрос — из окна скриншота;
  - ответ показывается в интерфейсе с моделью, расходом токенов и блоком рассуждений (если модель их возвращает);
  - перед отправкой рядом со снимком пишется `ai-request-*.json` — видно, что именно уходит;
  - ключ хранится только в зашифрованном виде (Windows DPAPI), в запросах он есть лишь в заголовке `Authorization`;
  - изображения отправляются только моделям, которые умеют их читать (OpenAI `gpt-4o*`, `gpt-4.1*`, `gpt-5*`, `o3*`, `o4*`). Для текстовых моделей (DeepSeek) уходит описание, заметка и контекст персонажа/билда.
- **Русские названия всех локаций кампании.** 90 зон получили русские подписи; названия из журнала на русском теперь сопоставляются напрямую, без ручной таблицы (таблица осталась для нестандартных случаев). Составные зоны показываются как «Нгакану → Сердце племени».
- **Документ о подписи кода** ([docs/CODE-SIGNING.md](docs/CODE-SIGNING.md)): зачем нужен сертификат, какие бывают, как подключить к CI.
- **История** различает события ИИ.

### Изменено

- Ограничение «сетевых запросов нет» снято осознанно: сеть используется **только** для явного запроса к ИИ, по нажатию кнопки, при включённом провайдере и сохранённом ключе. Никаких фоновых обращений, телеметрии и автообновлений.
- Домены запросов фиксированы (`api.deepseek.com`, `api.openai.com`), только HTTPS, редиректы запрещены.
- Версия 0.2.0: `Cargo.toml` и `tauri.conf.json`.

### Исправлено

- В подсказке для текстовых моделей теперь всегда передаётся заметка игрока (раньше она терялась).
- Актуализированы тексты интерфейса про ИИ и ограничения.

## [0.1.0] — 2026-11-12

Первый релиз Eni-PoE2-Companion: производная работа от [poe2overlay](https://github.com/maluramichael/poe2overlay) (MIT, © 2026 Michael Malura).

### Добавлено

- **Отслеживание игры**
  - автопоиск журнала: процесс игры, реестр Steam, `libraryfolders.vdf`, стандартные пути standalone;
  - поддержка `Client.txt` и `LatestClient.txt`, выбор самого свежего;
  - кодировки UTF‑8, UTF‑8 BOM, UTF‑16LE;
  - восстановление состояния после перезапуска игры/приложения (зона, уровень, область);
  - обработка усечения и замены журнала;
  - определение акта, шага кампании, следующей цели и следующей зоны;
  - история событий (зона, уровень, награда, задача).
- **Русский клиент**: разбор `[SCENE] Set Source [Берег реки]`, `достигает N уровня`, `Игрок … получил …`, фильтр служебных экранов (`Акт 1`, `(null)`), проверенные соответствия зон, сопоставление по внутреннему id области (`G1_1`, `G1_town`), ручное сопоставление неизвестных локаций с запоминанием.
- **Профили персонажей**: несколько профилей, имя/класс из журнала или вручную, уровень, акт, зона, история уровней, постоянные награды, выполненные задачи, привязка билда.
- **Билды**: локальный JSON-формат с валидацией, встроенный Lightning Arrow — Deadeye (5 этапов, 15 пунктов чек-листа), приоритеты экипировки, ссылки на первоисточники и дисклеймер.
- **Кампания**: маршрут 115 шагов / 6 актов (0.5.5) на русском и английском, режимы «все» и «только обязательные», переход по шагу, отметка выполнения, ручной выбор локации.
- **История**: фильтры по типу/профилю/поиску, экспорт JSON в «Документы».
- **Скриншоты**: захват клиентской области игры по горячей клавише, миниатюры, просмотр, тип снимка, заметка, SHA‑256, локальное хранение, кнопка подготовки запроса для ИИ (без сети).
- **Оверлей**: три режима (компактный/стандартный/расширенный), прозрачность, масштаб, положение, перетаскивание, скрытие, сохранение настроек, отсутствие перехвата фокуса, показ только при активной игре.
- **Настройки**: RU/EN, путь к журналу с проверкой, горячие клавиши с записью, папка скриншотов, таблица соответствий локаций, провайдер ИИ с ключом под Windows DPAPI, диагностика, сведения о лицензии.
- **Безопасность**: удалённая загрузка маршрута полностью убрана (данные встроены), белый список https-хостов для внешних ссылок, CSP ужесточён, capabilities ограничены `core:default`, состояние санитизируется, повреждённый `state.json` сохраняется как резервная копия.
- **Тесты**: 44 юнит-теста и 43 сквозные проверки интерфейса через WebView2 DevTools.
- **Документация**: README (RU), инструкция по установке и сборке, аудит безопасности, ограничения, описание интерфейса ИИ, NOTICE с атрибуцией.

### Изменено относительно poe2overlay

- Приложение переименовано в Eni-PoE2-Companion, идентификатор `io.github.bigbyon.enipoe2companion`, версия 0.1.0.
- Новый интерфейс: боковая навигация, семь разделов, тёмная тема с приглушённым золотом, полная русская локализация.
- Оверлей переработан: три режима вместо «панель/мини», новые горячие клавиши, масштаб и прозрачность.
- Маршрут кампании заморожен в приложении (обновляется вместе с релизом), вместо загрузки с внешнего сайта.
- Журнал: добавлены `LatestClient.txt`, UTF‑16LE, русские форматы строк, область и таблица алиасов.
- Скриншоты, профили, билды и история — новые модули.

### Исправлено

- Взаимная блокировка при обратном порядке захвата блокировок в диагностике и при повторном захвате в командах скриншотов (приложение могло зависнуть).
- Блокировка главного потока при показе/скрытии оверлея из потока-трекера.
- `state.json` с UTF‑8 BOM больше не считается повреждённым (частая проблема после правки в Блокноте).
- Строки повышения уровня без имени/класса больше не принимаются за уровень персонажа (защита от строк группы).
- Чат (`#`, `@`, `%`, `$`) больше не распознаётся как награда.
