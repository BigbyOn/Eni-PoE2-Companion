# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-11-12

Первый релиз Eni-PoE2-Companion: производная работа от [poe2overlay](https://github.com/maluramichael/poe2overlay) (MIT, © 2026 Michael Malura).

### Добавлено

- **Отслеживание игры**
  - автопоиск журнала: процесс игры, реестр Steam, `libraryfolders.vdf`, стандартные пути standalone;
  - поддержка `Client.txt` и `LatestClient.txt`, выбор самого свежего;
  - кодировки UTF‑8, UTF‑8 BOM, UTF‑16LE;
  - восстановление состояния после перезапуска игры/приложения (зона, уровень, область);
  - обработка усечения и замены журнала;
  - определение акта, шага кампании, следующей цели и следующей зоны;
  - история событий (зона, уровень, награда, задача).
- **Русский клиент**: разбор `[SCENE] Set Source [Берег реки]`, `достигает N уровня`, `Игрок … получил …`, фильтр служебных экранов (`Акт 1`, `(null)`), проверенные соответствия зон, сопоставление по внутреннему id области (`G1_1`, `G1_town`), ручное сопоставление неизвестных локаций с запоминанием.
- **Профили персонажей**: несколько профилей, имя/класс из журнала или вручную, уровень, акт, зона, история уровней, постоянные награды, выполненные задачи, привязка билда.
- **Билды**: локальный JSON-формат с валидацией, встроенный Lightning Arrow — Deadeye (5 этапов, 15 пунктов чек-листа), приоритеты экипировки, ссылки на первоисточники и дисклеймер.
- **Кампания**: маршрут 115 шагов / 6 актов (0.5.5) на русском и английском, режимы «все» и «только обязательные», переход по шагу, отметка выполнения, ручной выбор локации.
- **История**: фильтры по типу/профилю/поиску, экспорт JSON в «Документы».
- **Скриншоты**: захват клиентской области игры по горячей клавише, миниатюры, просмотр, тип снимка, заметка, SHA‑256, локальное хранение, кнопка подготовки запроса для ИИ (без сети).
- **Оверлей**: три режима (компактный/стандартный/расширенный), прозрачность, масштаб, положение, перетаскивание, скрытие, сохранение настроек, отсутствие перехвата фокуса, показ только при активной игре.
- **Настройки**: RU/EN, путь к журналу с проверкой, горячие клавиши с записью, папка скриншотов, таблица соответствий локаций, провайдер ИИ с ключом под Windows DPAPI, диагностика, сведения о лицензии.
- **Безопасность**: удалённая загрузка маршрута полностью убрана (данные встроены), белый список https-хостов для внешних ссылок, CSP ужесточён, capabilities ограничены `core:default`, состояние санитизируется, повреждённый `state.json` сохраняется как резервная копия.
- **Тесты**: 44 юнит-теста и 43 сквозные проверки интерфейса через WebView2 DevTools.
- **Документация**: README (RU), инструкция по установке и сборке, аудит безопасности, ограничения, описание интерфейса ИИ, NOTICE с атрибуцией.

### Изменено относительно poe2overlay

- Приложение переименовано в Eni-PoE2-Companion, идентификатор `io.github.bigbyon.enipoe2companion`, версия 0.1.0.
- Новый интерфейс: боковая навигация, семь разделов, тёмная тема с приглушённым золотом, полная русская локализация.
- Оверлей переработан: три режима вместо «панель/мини», новые горячие клавиши, масштаб и прозрачность.
- Маршрут кампании заморожен в приложении (обновляется вместе с релизом), вместо загрузки с внешнего сайта.
- Журнал: добавлены `LatestClient.txt`, UTF‑16LE, русские форматы строк, область и таблица алиасов.
- Скриншоты, профили, билды и история — новые модули.

### Исправлено

- Взаимная блокировка при обратном порядке захвата блокировок в диагностике и при повторном захвате в командах скриншотов (приложение могло зависнуть).
- Блокировка главного потока при показе/скрытии оверлея из потока-трекера.
- `state.json` с UTF‑8 BOM больше не считается повреждённым (частая проблема после правки в Блокноте).
- Строки повышения уровня без имени/класса больше не принимаются за уровень персонажа (защита от строк группы).
- Чат (`#`, `@`, `%`, `$`) больше не распознаётся как награда.
